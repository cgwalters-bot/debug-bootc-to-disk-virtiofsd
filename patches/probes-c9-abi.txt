The collector installs kprobe entry/return events for virtio_fs_enqueue_req and
an entry event for virtio_fs_request_complete, after requiring each symbol in
available_filter_functions or (for module functions) kallsyms. Entry request
pointers and thread IDs are the correlation keys. The return probe records the
signed function result as `ret=$retval`; it is associated with the entry request
through the originating task, while completion is keyed by request pointer
across worker threads. If symbols, tracefs, or permissions do not match,
readiness explicitly reports no/partial probes.
